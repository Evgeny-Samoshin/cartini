# Семантическое ядро CARTINI (черновой каркас)

> **Статус:** черновик фраз-кандидатов. Частотности НЕ проставлены — снять в
> Яндекс.Вордстате с регионом **Саратов** (операторы `"..."` и `"!...!"`).
> Города-спутники для геомодификаторов: Саратов, Энгельс.

## Как пользоваться

1. Открой `semantic-core.csv` в Excel / Google Таблицах.
2. По каждой фразе сними 3 частотности в Вордстате (регион = Саратов):
   - **W** — базовая (широкое соответствие);
   - **W"** — `"фраза"` (фиксация словоформ);
   - **W"!"** — `"!каждое !слово"` (точная).
3. Удали фразы с `W"!"` = 0 (нет спроса) и нерелевантные (см. минус-слова).
4. Дособери левую/правую колонку Вордстата — каркас неполный по определению.
5. Сортируй кластеры по сумме `W"!"` → это и есть порядок работ по страницам.
